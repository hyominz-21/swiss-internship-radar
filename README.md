# Swiss Internship Radar

🔗 **Visit the website:** [swiss-internship-radar.onrender.com](https://swiss-internship-radar.onrender.com)

I built Swiss Internship Radar to help me find internship and trainee opportunities at international organizations in Switzerland. My goal is to use an internship as a way to explore career opportunities and, if possible, build a future in Switzerland.

The site gathers specific openings with a confirmed Swiss location, including remote roles where working from Switzerland may be possible. Listings link to employers' official career pages so applicants can check details and apply directly.

**Please treat search results as a starting point:** vacancies, locations, eligibility and deadlines can change. Always confirm the details on the official posting before applying. Some employer sites block automated checks, so results may be incomplete.

## Run locally

Install Node.js 20 or newer, run `npm start`, then open [http://localhost:8787](http://localhost:8787). A web server is needed for live vacancy checks.

## Privacy

Saved jobs stay in your browser. Aggregate visit counts are measured with Cloudflare Web Analytics; the site does not keep a profile or personal record for each visitor. Applications go directly to employers.
